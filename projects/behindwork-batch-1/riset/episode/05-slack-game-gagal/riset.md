# Riset · Episode 05 · Stewart Butterfield: dua game gagal, dua produk besar (22 Nov 2026)

Kode klaim: `SB-xx`. Tingkat sumber: A primer, B sekunder kuat, C konteks (lihat `analisis/RISET-METODE-DAN-PILOT.md` §2).

**Judul kerja:** Game gagal, alat chat seharga 27,7 miliar dolar.
**Klaim inti:** Flickr lahir dari teknologi game gagal Game Neverending; Slack lahir dari alat komunikasi internal yang dibuat tim saat mengerjakan game gagal Glitch.
**Pelajaran:** Alat yang kamu buat untuk menyelesaikan masalahmu sendiri bisa lebih berharga daripada produk yang sedang kamu kejar.

Catatan akses: Medium (memo "We Don't Sell Saddles Here") mengembalikan 403 ke fetcher; isi dan tanggal memo dikonfirmasi lewat salinan (subtraction.com, A Letter A Day) dan halaman NFX. Halaman glitchthegame.com sekarang redirect ke slack.com (404); isi asli dibaca dari snapshot archive.org.
