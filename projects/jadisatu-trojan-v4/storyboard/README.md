# Storyboard Trojan v4: Semudah chat sama ayang

Ekspor dari Wonder, file Basilisk, halaman Motion Trojan v4, 7 November 2026. Sumber utama tetap di Wonder; folder ini salinan untuk dipindahkan.

- `storyboard-trojan-v4.pdf`: 40 panel berurutan, satu panel per halaman.
- `panel/`: 40 panel aktif, JPG selebar 960 px (08d 720 px), lengkap dengan caption.
- `pendukung/`: arah visual, tabel kritik, lembar karakter mouse.
- `aset/`: vektor kucing dan mouse (SVG), postingan kucing 4:5, karakter panel 03 penuh dan tanpa latar (PNG).

Panel adalah gambar, jadi tidak bisa diedit per elemen di sini. Waktu di caption masih sementara: VO akan disusun ulang mengikuti visual.

Rencana per beat ada di `content-ops/pieces/2026-11-07_jadisatu_motion-trojan-v4-storyboard.md`, standar build di `projects/jadisatu-trojan-v4/PROMPT-build-v3.md`.
