# contoh-gagal: rasa yang jelek

Satu file per kasus: `<kategori>-<deskripsi>.md` (+ still desain sendiri bila ada, ≤ 960 px). Isi: konteks slide (fungsi + urutan baca yang diminta), apa yang salah dilihat dari still, butir `guide/` yang menangkapnya, dan versi perbaikannya.

Dibuka bersama kartu saat merancang atau menilai visual, supaya yang jelek dikenali sebelum dibangun.
