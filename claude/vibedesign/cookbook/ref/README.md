# ref: gambar referensi

Repo ini **public**. Gambar karya kreator lain tidak disimpan di sini. Simpan gambar referensi dan crop beranotasi di folder Drive privat (subfolder per kartu), lalu tulis tautannya di frontmatter `sumber:` kartu.

Yang boleh disimpan di folder ini: sketsa atau crop dari desain buatan sendiri (≤ 1080 px), diberi nama `NN-<deskripsi>.png` sesuai ID kartu.
