# Profil merek untuk desain statis

Satu `DESIGN.md` per merek atau per proyek bila proyek punya dunia visual sendiri. Disimpan di `projects/<proyek>/DESIGN.md` (atau folder data merek pemilik). Isinya nilai pasti: palet, font, radius, bayangan, suara. Skill dan kartu tidak menyimpan nilai ini.

Format mengikuti spek DESIGN.md: blok token YAML di atas (normatif, bisa dicek), lalu prosa alasan per bagian. Urutan bagian: Overview → Colors → Typography → Layout → Elevation → Shapes → Motion → Voice → Components → Do's and Don'ts.
