# guide: pertimbangan per urusan

Isi `guide/` adalah kelas **P** (pertimbangan; `../../skill-steward/references/placement.md` §1): kesalahan kerja yang butuh menimbang konteks. Bukan template gaya dan bukan larangan umum; kondisinya (Pemicu) harus cocok dulu. Buka hanya urusan yang disebut langkahmu.

| Urusan | Dibuka saat | ID |
|---|---|---|
| `pesan/` | mengisi BRIEF, memilih bukti visual, menulis copy | PSN |
| `hierarki/` | menentukan urutan baca, sketsa, uji juling | HRK |
| `tipografi/` | memilih huruf, ukuran, penekanan kata | TIP |
| `komposisi/` | mengisi ruang kosong, menaruh elemen sekunder | KMP |
| `warna/` | memilih palet dan aksen | WRN |
| `karakter/` | memberi aksi dan pose pada maskot | KRK |
| `hindari/` | cek akhir tanda "AI slop" | HND |

Format butir: Pemicu → Anti-pola → Invarian → Karena → Boleh → Gerbang (`../../skill-steward/references/writing.md` §1). Butir baru diedit per ID, tidak ditulis ulang massal.
