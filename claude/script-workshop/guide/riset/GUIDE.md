# Riset & validasi

**Tujuan.** Konten berdiri di atas data, bukan di atas tebakan Irfan atau model. Irfan: "jangan cuma andelin dari aku. Kayaknya kamu dari tadi nggak ada nyari riset sama sekali" (6 Nov).

## Cara
1. Tulis hipotesis Irfan satu kalimat. Contoh: "UMKM bermasalah di pencatatan administrasi → kelebihan stok, pembukuan tidak teratur."
2. Cari 3–6 sumber: survei/laporan (BPS, Kemenkop UKM, bank, asosiasi, penyedia POS/akuntansi), berita dengan angka, studi akademik. Utamakan Indonesia dan ≤ 3 tahun.
3. Putuskan: **didukung / dibantah / campur**. Tulis angka + link per poin.
4. Dibantah atau tipis → ubah sudut, jangan dipaksakan. Campur → itu sering sudut paling menarik.
5. Angka di naskah dibulatkan wajar dan tetap setia sumber; sumber dicantumkan di caption/slide akhir bila diklaim.

## Membingkai sesuai kekuatan bukti
| Bukti | Cara bicara |
|---|---|
| Pengalaman Irfan sendiri | "aku …" |
| Kejadian di keluarga/teman yang Irfan ceritakan | "orang tuaku …", "temen-temenku …" (fakta, bukan dugaan; Irfan 7 Nov) |
| Data bersumber | "data X bilang …" |
| Hipotesis / belum diuji | "aku curiga …", "gimana kalau …?" |
| Tidak ada | jangan ditulis |

## Data di naskah: secukupnya
Riset untuk **memastikan kita tidak salah**, bukan untuk dibacakan. Statistik lembaga atau studi kasus tanpa nama yang tiba-tiba muncul di VO terasa tempelan dan bikin konten jadi "informasi" yang berat (Irfan 7 Nov: studi kasus + data OCBC "makin gak nyambung"). Masukkan ke VO hanya bila ia bagian alami dari cerita; selebihnya di caption.

## Cek cepat
- Setiap angka punya link? Setiap "ternyata" punya bukti?
- Ada data yang membantah dan sudah ditimbang (devil's advocate)?
