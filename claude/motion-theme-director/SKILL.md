# Motion Theme Director (penunjuk)

Isi skill ini dipindahkan ke [`../motion-graphic/references/dunia-visual.md`](../motion-graphic/references/dunia-visual.md): urutan kerja, router tema, tabel terjemahan kata gaya brief, inti lintas tema, anggaran per frame, gerbang 3 style frame, dan 5 uji biner. Pintu video sekarang `../motion-graphic/SKILL.md`; buka `dunia-visual.md` dari langkah 3 alurnya.

File di folder ini tetap berlaku sebagai bahan: `BEDAH-REFERENSI.md` (bedah referensi jadi REF-SPEC, Phase 0), `tema/*.md` (6 tema dengan keyframe), `PRESET-INDEX.md` (hanya di tahap build). Sistem huruf, sistem material, dan terjemahan kata gaya mengikuti NEGATIF v2 di `../motion-graphic/SKILL.md`; butir [mutlak] menang bila ada bentrok, selebihnya REF-SPEC proyek.
