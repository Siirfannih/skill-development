# SUMBER · skill-steward

Provenance of this skill. Instruction files carry no names, dates or stories; they live here.

- Built from an audit of the repo's governance rules (85 rules, 20 conflicts, 17 duplicates, 19 stale references, 16 gaps) and from mechanisms adapted from five upstream skill repositories (`references/attribution.md`).
- First design: one dedicated steward agent, branch per change, tiered approvals, second-model checks. Replaced at the owner's request by the current design: purpose first, judgment over procedure, works with one model and no helpers, three approval levels (Mechanical / Behavior / Risky), owner requests are their own approval.
- Language policy: English instruction files, Indonesian owner-facing text, gradual migration. Owner correction during the first migration batch: examples of how the owner phrases feedback are illustrations and are translated; only output samples whose wording is the point and literal values matched by scripts stay Indonesian.
