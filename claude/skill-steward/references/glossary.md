# Glossary

Open when naming a concept or translating a term. Add a new term here before using it; one English term per concept. File names, IDs and machine markers keep their original form.

| Indonesian | English | Meaning |
|---|---|---|
| kartu | card | one cookbook entry: a reference dissected into reusable mechanics |
| kiblat | north-star card | the card a project takes its style from |
| pack | pack | a numbered group of cookbook cards (01–06), used as a filter |
| Catatan pakai | usage note | note on a card about using that style; whether cards keep it is an open item in `steward/backlog.md` |
| mekanik | mechanic | the style-free mechanism behind a reference |
| kulit | skin | a reference's surface look; copied without a reason, it is a defect |
| kenapa bekerja | why it works | card column: the perceptual reason a mechanic works |
| REF-SPEC | REF-SPEC | measured spec of a chosen reference (colour, type, layout, material, motion), with a reason per choice |
| simpangan | deviation | a departure from REF-SPEC beyond tolerance |
| takaran | dosage | how much of a technique is used |
| sidik jari | fingerprint | a repeated layout that marks generic output |
| resep, RESEP.md | recipe | a project's plan: concept plus 2–4 cards, with reasons |
| subagen | subagent | a model started by another model for one task; it knows only its brief |
| uji baca dingin | cold-read test | reading a brief as the subagent would, to predict what it will produce |
| rantai tujuan | goal chain | goal → unit of work → deliverable → acceptance metric, all pointing at the same thing |
| kombinasi primitif | primitive combo | a saved combination that only references primitive ids (not a project recipe) |
| uji atomik | atomic test | split a primitive if a part can be removed and the rest still works alone |
| uji tukar slot | slot-swap test | render a primitive with two slot fillings unlike the reference; passes only on motion, not on look |
| jangan dicuri | do-not-steal list | reference skin elements that must never appear in a primitive's output |
| wadah | container | the shape a subject sits in (card, folder, circle); always a slot |
| lembar kontak | contact sheet | tiled frames for mapping structure; never for measuring motion |
| jendela gerak | motion window | the time range of one movement, measured at native fps |
| larangan rangkai ulang | re-sequencing ban | no three or more primitives from one reference in the reference's own order |
| arsip bedah | deconstruction record | per-reference analysis file; not loaded in editing sessions (distinct from archive) |
| racikan | card mix | table of which card serves which beat; approved with the storyboard |
| beat | beat | one story unit of the script and storyboard |
| lantai, LANTAI.md | floor | quality rules valid in every style (archived in motion-graphic, active in vibedesign) |
| NEGATIF | NEGATIF | the 10 shared anti-slop limits in `claude/_bersama/NEGATIF.md`; name kept |
| [mutlak] | [mutlak] (absolute) | tag on NEGATIF items that no style may override; changing them is Risky |
| saringan, SARINGAN.md | filter | the older promotion filter for lessons; its rules move into this skill |
| pelajaran | lesson | a judgment rule from a real error, stored as an ID'd guide item |
| kelas S / P / H | class S / P / H | project taste / judgment lesson / hard law (placement.md §1) |
| Cara memutuskan | How to decide | the guide section that holds lesson items |
| urusan | domain | a guide area and its ID code (teks → TKS, gerak → GRK) |
| Pemicu | Trigger | lesson field: what is visible before the error happens |
| Anti-pola | Anti-Pattern | lesson field: the class of error observed |
| Invarian | Invariant | lesson field: what must be true, with a number |
| Karena | Because | lesson field: the effect on viewer or quality |
| Boleh | Allowed | lesson field: legitimate exceptions |
| gerbang | gate | a check that must pass before the next stage |
| gerbang pemilik | owner gate | a point that needs my approval (script, storyboard with card mix, first render) |
| juri | judge | the checking scripts in `scripts/juri/` and the judging role |
| salah-tembak | false positive | a gate failing work that is good |
| tahap | stage | Brief → Script (Naskah) → Storyboard/block out → Animate → Effects & grade → Mix → Deliver |
| TAHAP.md | TAHAP.md | per-project stage checklist with evidence |
| DECISIONS.md | DECISIONS.md | per-project ledger of my corrections and choices; stays Indonesian |
| SUMBER.md | SUMBER.md | per-skill provenance log; never an instruction |
| PENDING.md | PENDING.md | old queue of lessons awaiting my answer; being retired into `steward/inbox/` |
| Rute | route | one row of the route table in PETA.md, generated by `tools/peta.py` |
| arsip | archive | under `archive/` (placement.md §3) |
| preset | preset | a ready component or setting listed in a registry (`PRESET-INDEX.md`, `pabrik/registry.json`) |
| primitif | primitive | a style-free mechanical component (`toolkit/`, `pabrik/`) |
| pabrik | factory | the pipeline that turns references into tested primitives |
| slot | slot | a named field to fill: in a template or profile, or a primitive's replaceable parameter |
| profil merek | brand profile | per-brand settings checked by `profil_cek.py` |
| contoh-gagal | failure example | a rejected frame with a one-sentence cause, in `cookbook/contoh-gagal/` |
| uji transfer | transfer test | running a skill draft on a brief it was not written from |
| uji no-op | no-op test | the before-and-after behavior check; the before run is the baseline (testing.md §3) |
| dilihat bergerak | seen in motion | a card flag: the source was watched as video, not stills |
| Sutradara | Director | the session that talks with me, plans and judges |
| Editor, pekerja, builder | builder | the worker subagent that builds, renders and reports with evidence; never judges its own output |
| Devil's Advocate | Devil's Advocate | an outside critic that attacks a plan or output before acceptance; advice, not a gate |
| perawatan | maintenance run | a session that improves or cleans the repo (maintenance.md §1) |
| mekanis / perilaku / berisiko | Mechanical / Behavior / Risky | the approval levels of a change (SKILL.md §4) |
| laporan perubahan | change report | Indonesian report of one Behavior or Risky change in `steward/changes/`; request and record (maintenance.md §3) |
| catatan inbox | inbox note | one possible general lesson per file in `steward/inbox/` (maintenance.md §2) |
| sudah diputuskan | Decided row | a row under "Decided" in `steward/backlog.md` (maintenance.md §3) |
| cek sendiri | self-check | a check you ran yourself from a fresh read, labelled so (testing.md §3) |
| setengah arsip | half-archive | a file outside `archive/` that says it is archived; an error |
| hukum keras | hard law | a rule wrong in any style and measurable pass/fail; lives in a check (placement.md §1) |
| backlog | backlog | open conflicts and ideas in `steward/backlog.md`, with a "Decided" section |

## Common rule words

When you search for existing instructions (SKILL.md §3 step 2), search both words: wajah · face, teks · text, tenggat · deadline, lewati · skip, potong · cut, warna · colour, huruf · font, gerak · motion, kamera · camera, suara · audio.
