# Template gaya

Satu folder = satu gaya edit yang bisa dipilih di gerbang 1. Gaya terpilih menjadi rujukan visual utama untuk video itu: Sutradara memakainya untuk merencanakan, Editor untuk membangun (Irfan 11 Nov). Urutan menang tetap: instruksi Irfan → `projects/<proyek>/` → `SKILL.md` → gaya terpilih → `guide/`.

| Gaya | Untuk | Engine |
|---|---|---|
| `minimal-premium/` | talking head/podcast tenang, edukatif, filosofis (ref 18 Arthur Brooks) | Remotion; sebagian adegan bisa lewat `engines/talking-head-reels` |
| `editorial-bold/` | talking head cepat, opini, hook provokatif (skill talking-head-reels) | `engines/talking-head-reels` (EDL) |

Brief tidak cocok dengan keduanya = Sutradara mengusulkan satu gaya ke Irfan atau bekerja dari `guide/` saja; jangan memaksa gaya.

## Rencana edit berbentuk menu (gerbang 4 untuk klip/talking head)
Sutradara menulis `handoff/MENU.md` setelah transkrip dan potong jeda:
```
## B03 · 0:12.4–0:15.9 · peran: menjelaskan
> "I'm going to be a barista. And I fell in love with a girl in San Diego."
| Opsi | Adegan | Ide satu baris | Contoh ref |
| A ✔ | MP-03 lukisan + teks | dua lukisan: barista, pasangan berciuman; "San Diego" serif besar | ref18 14:08 |
| B | MP-02 B-roll + teks | barista menuang kopi, kota pantai | ref18 2:24 |
| C | MP-01 wajah + caption | tetap di wajah, "barista" besar | ref18 1:28 |
Catatan Irfan: …
```
- 3 opsi per beat, semuanya dari menu adegan gaya terpilih; opsi A = rekomendasi Sutradara + alasannya dari tabel penempatan.
- Tiap opsi menyebut contoh referensi (file + timestamp) agar Irfan bisa melihatnya.
- Irfan memilih/mencoret/menulis catatan (target ±15 menit). Klip tanpa kesempatan bertanya: Sutradara memilih opsi A dan mengirim MENU bersama hasil (`storyboard.md` §1).
- Pilihan masuk ke `PLAN.json`; MENU disimpan sebagai bukti keputusan.

## Membuat gaya baru (metode ref 18)
1. Kumpulkan 10–20 video terbaik dari satu kreator/gaya.
2. Bedah sebagai editor: untuk tiap adegan tanya kenapa adegan ini, desain ini, warna ini, efek ini, animasi ini.
3. Kelompokkan adegan menjadi menu bernama (biasanya 6–12 jenis). Per jenis: font, warna, ukuran, tekstur, pola gerak, durasi.
4. Tabel penempatan dari data: tiap animasi dicatat kalimat pemicunya dan peran kalimatnya (`analysis-qa.md` §2).
5. Simpan `STYLE.md` dengan bagian yang sama seperti dua gaya di atas (token, menu adegan, penempatan, audio, aset, cek QA, engine) + contact sheet di `guide/referensi/sheets/`.
6. Tambah baris di tabel ini. Gaya baru dipakai setelah Irfan melihat satu still per jenis adegan.
