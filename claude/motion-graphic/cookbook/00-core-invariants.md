# 00 · Core Invariants (Lintas Semua Format)

> **Otoritas:** Brief aktif → `projects/<proyek>/` (`DECISIONS.md`, `RESEP.md`) → `BRAND.md` + `EDITING.md` → kartu terpilih → file ini. Default aman mencegah AI slop; pengecualian editorial AE resmi dicatat di `RESEP.md` / `EDITING.md`.

1. **Satu lapisan teks ucapan (`A1`, `A3`, `A5`).** Seluruh ucapan tampil sebagai satu sistem tipografi kinetik tanpa pita subtitle terpisah atau kata berulang ganda. Pita bawah hanya sah untuk label identitas non-ucapan (1× saat tokoh diperkenalkan).
2. **Zona aman & kontras (`A2`, `A4`, `A7`, `C16`).** Teks ucapan berada dalam margin aman 5%, berjarak ≤ 8% dari subjek, bebas wajah/logo, ≥ 4,5:1, 1–3 kata/tampil, maks 2 baris. Pengecualian *editorial bleed* tepi hanya untuk teks grafis non-ucapan bertanda `role: bleed-display` di `RESEP.md`.
3. **Satu sistem penekanan per frasa (`A6`, `C14`).** Maksimal satu mode penekanan dalam satu frasa (dilarang mencampur regular + bold + serif italic sekaligus dalam satu baris); kata hero diletakkan di bidang bersih tanpa menimpa thumbnail atau kartu UI.
4. **Gerak terkurva & transisi bermotivasi (`B10–B13a`).** Shot > 2 dtk hidup (push/pan/drift); nol linear easing; ≥ 4 tipe transisi/30 dtk lewat `SceneChain` + `curves.ts`. Default nol crossfade; pengecualian *micro-blend ≤ 4 f* hanya di puncak *match-cut/zoom-through* (`scale ≥ 3×` atau objek ≥ 80% layar) atau *blur-to-sharp* yang dipadu gerak.
5. **Objek 2.5D/3D, UI riil vs konseptual & anti-spam (`C14`, `D19–D22c`).** Objek 2.5D/3D boleh dipakai sesuai `EDITING.md`, tetapi **dilarang** memakai kombinasi AI slop: Apple Glass berlebihan + radial glow biru/ungu generik, spam grid simetris (> 4 kartu identik — pakai 3–4 elemen organik), multi-fokus (> 2 objek berebut mata), atau bezel hardware ponsel yang tidak perlu. Merek publik (Claude, ChatGPT, IG, Threads, GitHub) wajib mengikuti UI aslinya; sistem kerja sendiri boleh memakai *editorial UI metaphor* frameless. Saat ragu komposisi, cek keyframe referensi utama; jika pola tak ada di referensi, jangan dikarang. Frame 0 hidup tanpa placeholder.
6. **Audio utuh, 5 Pilar & level relatif VO (`E23–E25a`).** VO `TEMPO=1.0`, tanpa potong fonem atau limiter keras. SFX 5 Pilar (`bed`, `transisi`, `tick`, `taktil`, `aksen`) dimulai dari `0 dB` pre-fader; di mix akhir impact/transisi `−2…−6 dB` dan tick `−12…−18 dB` relatif VO. `kt_tick` memilih mode `per-word` (explainer/UI) atau `accent-only` (dokumenter/talking-head tenang) di `EDITING.md`.
7. **Brief Sanitizer, model worker & efisiensi (`F26–F29`).** Sebelum build, bandingkan brief user terhadap referensi utama: bila instruksi user memicu *AI-Slop Trigger* (kata *"premium"* tanpa acuan, permintaan glass/glow, campur 3 gaya huruf, atau konflik referensi), **berhenti 1 turn untuk konfirmasi opsi aman**. Setiap `Agent()` **wajib mengisi `model: "sonnet"`/`"haiku"` eksplisit** (maks 60 turns, 10 gambar via contact sheet). Urutan: visual (`frame_audit.py`) → audio (`audio_phone.py --gate`) → `render.sh final`; revisi per diff (`revisi_cek.py`).
