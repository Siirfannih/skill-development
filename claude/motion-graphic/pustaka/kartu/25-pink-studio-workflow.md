## TEKNIK (boleh dipinjam referensi lain; selalu dikenakan pengikat kiblat)

### 4. B-roll / footage
- Tidak ada footage kamera; semua render 3D (Blender + After Effects, sesuai isi kursus) ditambah satu rekaman UI halaman kursus (20,5–21,5) dan panel halaman "One course Teaches Full" yang naik dari bawah (17,4–18,6, panel ±22 % tinggi).
- Dunia yang dipakai: meja overhead dengan ponsel dan bubble komentar, ruang kerja, tombol Publish, laptop + headphone, cangkir pensil/marker, papan gambar, pita, huruf balon, payung di langit, folder kartu, UI.

### 5. Motion graphic
- Bubble komentar 3D ("bro pls its taking forever") melayang dari ponsel = suara penonton; kursor 3D menekan "Publish" = peluncuran; huruf balon "many" + catatan tempel pertanyaan = banyak kebingungan; payung = jawaban; folder terbuka jadi kartu berlabel (`.aep`, `.blend`).
- Watak: benda melayang pelan dan berputar sambil kamera terbang; pukulan grafis terjadi pada aksen musik.
- **Skala subjek:** berganti tajam. Meja overhead = banyak objek kecil (ponsel ±10 % lebar). Tombol Publish = satu subjek besar 70 % lebar × penuh tinggi area letterbox. Payung = satu subjek ±22 % lebar × 33 % tinggi di tengah langit kosong. "Real" = huruf memenuhi 100 % lebar.
- **Kedalaman:** 3 lapis di shot 3D: objek depan sangat buram (DOF), subjek tajam, latar buram/bloom. Paralaks nyata karena kamera 3D bergerak. Babak datar: 1 lapis + vignette.

### 6. Kamera & transisi
- Kamera 3D tidak pernah diam di babak 3D (estimasi cv2 per 0,25 dtk): meja overhead berputar ±28° sambil naik (skala ×0,50); Publish push-in ×1,6; laptop orbit + pull ×0,7; papan gambar berputar ±50°; pita push-in ×1,6. Babak langit hampir diam (×1,01). UI pull-out ×0,70. Logo nyaris diam (×1,05).
- Letterbox beranimasi: bar hitam 25 px (5,0 dtk) → 158 px per sisi (6,0–7,0 dtk, area gambar ±2,3:1) → 97 px (8,5) → 0 (9,5). Dipakai untuk momen "Publish / IT'S LIVE".
- Jembatan antar-dunia = letupan radial 4–6 frame (0,17–0,25 dtk): 9,08 (garis radial + sobekan kertas ungu tua menyapu), 11,33 (kilat magenta), 15,50 (warna terbalik: magenta → biru-sian → pink → putih, payung tetap di tengah). Cut keras dengan 1 frame smear (3,17) dan pemotongan langsung (13,375 ke pita, 23,125 ke "projects").
- Halaman UI → 1 frame putih → kedip "start!!!!!" (21,5–21,96).
- Pemicu: aksen musik/whoosh, bukan kata (tanpa VO).

### 7. SFX
- earshot: 143 event (5,4/dtk); berlabel 45 whoosh, 26 drum, 13 hit, 7 foley (pop, kertas), 1 riser, 1 klik/spasi.
- Whoosh/swish menempel tiap perpindahan dan objek melayang (0–2,5 dtk tiga whoosh beruntun); boom sinematik pada cut 2,8–3,1 dtk; pop gelembung pada bubble komentar; kertas pada folder (18,75); riser terbalik sebelum "projects".
- Level: SFX setara musik (puncak −1 s.d. −7 dBFS), tidak di bawahnya.

### 8. Musik
- Glitch hop / elektronik dengan snare roll, scratch, dan vocal chop (earshot); librosa ±108 bpm (earshot ±88 bpm, pulsa lemah 0,21); nada dominan C#/F/D#.
- Babak: 0–6,85 intro tipis −17 LUFS → 6,85–16,15 drop agresif −13 LUFS (paling keras 7–10 dtk) → 16,15–26,4 vocal chop −16 LUFS.
- Mix −14,7 LUFS, true peak −0,5 dBTP (melewati −1), LRA 4,1 LU. Tanpa VO.

## Cek kemiripan (dipakai juri saat menyandingkan still)
- Latar shot 3D ungu muda (±`#C591D9`–`#D2A4DD`) atau langit `#C4D8DF`; babak datar off-white hangat `#F0EFEB` dengan sudut lebih gelap, bukan putih murni.
- Teks datar magenta (±`#E2177E`/`#E00AE1`) atau ungu tua `#1F183A`; tidak ada hitam murni.
- Ada still kata raksasa dengan cap ≥ 80 % tinggi frame yang terpotong di tepi, dan still kata yang sama besarnya 5–7 % di tengah.
- Teks utama di adegan objek berada di belakang subjek (subjek menutup sebagian huruf), cap ±16 %, anak kalimat ±6× lebih kecil berwarna pink/ungu.
- Shot 3D punya DOF terlihat: objek depan buram, subjek tajam, latar buram; ada titik halftone di tepi.
- Kursor ungu 3D besar (±`#9139A5`) muncul menekan/menunjuk minimal sekali.
- Still transisi menunjukkan letupan radial atau warna terbalik (magenta/sian), panjang 4–6 frame, bukan dissolve.
- Ada momen letterbox beranimasi (bar ±22 % tinggi per sisi) untuk klimaks.
- Tiap shot 3D berbeda frame awal-akhir (push ×1,6, putar 28–50°); tidak ada shot 3D diam.
