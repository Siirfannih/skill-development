## PENGIKAT (diambil utuh dari SATU kiblat; ini yang membuat video terasa satu keluarga)

### 1. Warna & tekstur
- Hook 3–7 dtk berlatar oranye `#B5400F`–`#BE450F`, lalu dasar merah-hitam: hitam `#010101`–`#030200`, dinding merah tua `#5E0205`, karpet bulat `#8C0306`, latar merah penuh `#AF071B` → `#520005` di sudut.
- Teks: putih, merah `#ED2F3D`, krem `#FDE3CC` (judul condensed). Aksen sekunder: teal/hijau mint `#78FCD1` (angka pixel, kotak PROMPT, CTA), oranye robot/angka, kuning lampu.
- Vignette kuat di semua adegan gelap (luma tengah:sudut 84:17 di latar merah, 43:18 di CTA).
- Tekstur: kubus voxel (meja, lampu, tanaman), tokoh sprite pixel 2D di dunia 3D, bloom pada layar/lampu, glitch RGB-split pada kata tertentu, mozaik kotak merah/putih/hitam untuk transisi.
- Pembuka satu-satunya adegan terang: foto meja di padang rumput (langit `#0E74A4`).

### 2. Teks
- Tiga keluarga: sans geometris sangat tebal, bulat (mirip Gilroy ExtraBold/Clash Display) untuk narasi; condensed tebal (mirip Bebas Neue/Anton, kadang italic) untuk vonis ("WRONG QUESTION.", "NO MAGIC", "SYSTEM", "CLAUDE"); font pixel/dot-matrix teal atau oranye untuk angka ("0110", "50", "00111", "38%"). Label kecil monospace ("QUESTION: INVALID", "CONTINUE WITH TUTORIAL PART 2").
- 1–4 kata per tampil; kalimat dipecah: kata sambung kecil di atas, kata kunci besar di bawahnya ("as a / skill file.", "His name's / MIFTAHUL", "There is / NO MAGIC", "Comment / SKILL").
- Kata kunci 11–27 % tinggi frame, kata sambung 4,7–7,6 %; rasio 1,6–2,5×.
- Posisi: di sisi kosong lawan tokoh (tokoh kiri → teks x 60–75 %; layar kanan → teks x 17–27 %); di pembuka kata MEMBINGKAI monitor (atas kiri, atas kanan, "VIRAL" melintang di bawah).
- Penekanan: warna (merah atau hijau) + ganti font ke condensed; kata dicoret ("prompt?" dengan coretan merah), glitch RGB pada satu kata ("thirk", "S"), kata ditulis ulang setengah jalan ("hard pa").
- Masuk sigap: ketik per huruf dengan kursor ("as a|"), per kata muncul satu-satu, atau kata miring di bidang 3D yang ikut perspektif kamera ("Ask it for a cool"); keluar dengan glitch/terurai atau terbawa push kamera. Skill file di layar sendiri berbunyi "Text moves in 3D, never flat".

### 3. Ritme
- 37 cut = 18,5/menit, shot median 2,1 dtk; event visual 45/menit (pace_read).
- Babak cepat 0–43 dtk: 32 cut/menit (hook, latar merah, close-up, meja voxel). Babak panggung 43–105 dtk: 11 cut/menit, kamera bergerak di dalam satu set 3D. Penutup 111–120 dtk diam di CTA.
- Jeda bunyi 0,3 dtk berulang di babak cepat; hening total 0,5–1 dtk sebelum dua bagian penting (89 dtk, 109 dtk). Musik berhenti di 42,6 dtk = pindah dari hook ke penjelasan.

## TEKNIK (boleh dipinjam referensi lain; selalu dikenakan pengikat kiblat)

### 4. B-roll / footage
- Hampir tidak ada footage nyata. Sisipan: foto meja di rumput (pembuka), ilustrasi kafe pixel malam ("over 500 people already have"), video kecil di bingkai kaca dengan judul di atas ("And this", "It's already the TUTORIAL").
- Interlude kosmik 44–50 dtk: galaksi, matahari, bulan abu-abu dengan teks putih kecil 2–3 kata di tengah ("But first,", "one thing I have to show you").
- Rekaman layar dijadikan objek 3D: editor SKILL.md di monitor voxel, timeline edit di layar, kartu thumbnail mengambang.

### 5. Motion graphic
- Ucapan → aksi tokoh: "His name's MIFTAHUL" = close-up wajah; "isn't selling you a course" = detektif di samping kotak COURSE $$$ dengan label callout nama; "a whole CREW" = ikon Script/Storyboard/Animation/Captions/Voiceover/Sound design berjajar dengan garis titik; "50 kilobytes" = angka pixel oranye di grid teal; framework = kanvas 4 warna yang terisi 38 % → 75 %.
- Label callout tipis (garis + titik oranye + nama monospace) menunjuk tokoh.
- **Skala subjek:** satu tokoh besar: close-up kepala ±76 % tinggi; detektif di panggung 53–62 % tinggi, robot 20–35 %; adegan alur: banyak objek kecil (tokoh ±25 %, ikon ±10 %).
- **Kedalaman:** 3 lapis: dinding/rak/bingkai merah-teal buram di belakang, tokoh tajam di tengah, karpet/meja depan buram (ketajaman bawah 26 vs tengah 661). Vignette + bloom. Teks melayang di lapis tengah, kadang ditutup objek.

### 6. Kamera & transisi
- Push-in hampir terus: +2…+4 %/dtk saat tenang, hentakan +11…+30 %/dtk pada kata kunci; per shot +5 … +55 %. Pull hanya untuk reveal (−28 % di 32 dtk, −48 % di 98 dtk). CTA terkunci.
- Set voxel dilihat dari atas, depan, dan tiga perempat; teks ikut perspektif kamera.
- Transisi: mozaik kotak merah/putih/hitam memenuhi frame (±3 kali), zoom-through ke layar monitor (pembuka), glitch/kilat putih, whip pada ganti latar. Pemicu: kata pergantian topik ("Here's the part", "So,", "Let's cook").

### 7. SFX
- earshot: 752 event (6,3/dtk), 96 berlabel: 20 nada glockenspiel/pluck, 10 UI (chat pop, tap, rana kamera), 8 hit (sub bass drop), 8 foley (bubble/cork pop, balok kayu), 7 whoosh/swish, 3 ketikan keyboard, 2 langkah kayu, 1 riser (reverse cymbal 39,9 dtk).
- Pemakaian: glockenspiel/pop = kata atau ikon muncul; ketikan = teks diketik; whoosh = ganti adegan/whip; sub bass drop = vonis dan pindah babak (42,9 dtk, 86,9 dtk, terkuat 94,7 dtk +48 dB di atas dasar); langkah kayu = tokoh bergerak. Skill file di layar: "A sound for every motion".
- Sinkron: 88 % cut punya onset dalam 100 ms (median selisih 32 ms); 12 % jatuh di aksen kuat.
- Level: SFX puncak −2 … −6 dBFS, setara suara; tidak ditaruh di bawah VO. Level pasti terhadap suara: Tidak terukur: tanpa stem.

### 8. Musik
- Hanya babak pembuka 0–42,6 dtk: glitch hop dengan vocal chop (AST music 0,30–0,52), ±112 bpm (librosa), tanpa grid beat tegas (pulse clarity 0,03).
- 42,6–120 dtk musik praktis hilang (AST music 0,00–0,02): VO + SFX nada/pop saja; tekanan dibawa sub bass drop.
- Mix keras dan rata: −14,1 LUFS, true peak −0,4 dBTP, LRA 2,4 LU; 12 jeda 0,3 dtk (5, 6,4, 20,5, 23,4, 24,7 dtk …) dan hening total 89 dtk, 109 dtk sebelum bagian penting.
