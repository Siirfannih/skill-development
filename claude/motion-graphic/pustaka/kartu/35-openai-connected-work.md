### 5. Motion graphic
- Garis bercabang: satu garis bergelombang masuk dari kiri ke titik biru, lalu 6 cabang mekar ke ikon ujung (surat, globe, kalender, gambar, kode, jam) dengan label + subjudul abu.
- Cincin: cincin biru membesar menembus kamera → putih → "connected." di tengah; berlanjut ke wordmark.
- Kotak prompt kaca di atas pantai, tombol biru; kartu poster tipografi warna-warni (±14 kartu) meledak memutar dari tombol.
- Editor kode gelap: centang hijau per baris, satu baris error merah dengan "Fixing Issue…", kubus biru 3D di sudut editor.
- Pohon data: label oranye melayang (Clients, Feedback, …) terkumpul membentuk pohon bertekstur dengan bunga sakura, daun, angka naik/turun (hijau/merah).
- **Skala subjek:** satu subjek besar per adegan: cincin Ø 79 % tinggi (44 % lebar); kotak prompt 67×10 %; editor 65×68 % (lalu 90×74 % saat dekat); pohon menyebar 94×91 %; garis cabang 96×76 % tapi piksel terang hanya 1,2 % frame (tipis, banyak ruang hitam).
- **Kedalaman:** 2–3 lapis: foto alam (latar) + UI melayang berbayangan lembut + label/kartu depan; adegan label krem punya 3+ ukuran label (2,1 / 3,1 / 5 % tinggi) = lapisan Z, kamera terbang melewatinya; latar putih babak 2 memakai gradien radial; foto tidak diburamkan, tetapi poster/kartu di tepi diberi blur gerak.

### 6. Kamera & transisi
- Kamera hampir tak pernah diam. Terukur (ORB, per 0,2 dtk): pan kiri mengikuti garis 2,2–5,6 dtk (−9 → −2 % lebar per 0,2 dtk, melambat); pull-out dari pantai −9 → −2 %; push ke kotak prompt +6 → +13 %/0,2 dtk; pull −3 %/0,2 dtk dari editor; push pelan +0,5–2 %/0,2 dtk di pohon dan langit; drift sangat kecil (≤ 0,7 %) saat "diam".
- Transisi: zoom-through cincin (7,7 dtk, dipicu bunyi pop), zoom keluar logo → pantai (11,3), menembus tombol kirim → ledakan kartu (13,3), kartu menyebar ke luar → "Seconds." (14,9), whip vertikal ke atas 2× (17,4 dan 19,7; 31–37 % tinggi per 0,2 dtk) masuk/keluar close-up merah, label melayang → pohon (21,0), crossfade ke langit (26,6).
- Pemicu: gerak objek (garis, cincin, tombol, kartu) memimpin ke adegan berikutnya, bukan cut keras.

### 7. SFX
- Kosakata (earshot, label CLAP = petunjuk): pop/bubble UI (chat message pop) untuk label dan teks muncul, klik shutter di awal, impact hit + sub-bass drop di pergantian besar, 3 whoosh tipis (whip), "Fixing Issue" ketukan kecil.
- 221 onset (7,1/dtk), 96 bertag: 34 hit, 32 UI, 9 drum, 3 whoosh. Aksen terkuat: 7,07 dtk pop +40 dB di atas latar (masuk cincin), 2,69 dtk impact +31 dB ("thoughts"), 0,46 dtk klik +30 dB.
- SFX dicampur sejajar musik (puncak −0,3 hingga −8 dBFS), bukan jauh di bawahnya.

### 8. Musik
- House/tech house dengan vocal chop, ±108 bpm (librosa & earshot), pulsa lemah (clarity 0,18).
- Babak 1 (0–7 dtk) tipis −19 dB RMS, centroid 2,1 kHz; drop mulai 7,05 dtk (cincin) penuh −14 dB RMS; akhir mereda −18 dB.

## Cek kemiripan (dipakai juri saat menyandingkan still)
- Hanya satu aksen biru (±`#0859F8`/`#0739CF`) di teks dan objek; merah hanya untuk error.
- Teks kunci di tengah layar (pusat x 50 ± 5 %, y 45–52 %), 6,5–12 % tinggi frame, 1–4 kata.
- Penekanan lewat warna biru, bukan bold/kotak; kata sambung biru 1,5–2× lebih kecil dari kata kunci, atau seukuran di penutup.
- Babak gelap: latar `#020305` tanpa grain, garis putih ±1 px, piksel terang ≤ 2 % frame.
- Satu subjek besar per adegan: cincin ±80 % tinggi, editor ±65 % lebar, kotak prompt ±67 % lebar.
- UI duduk di atas foto alam terang berkabut penuh layar, dengan bayangan lembut; tidak ada bingkai.
- Label kecil (2–3 %) selalu menempel ujung garis/titik, dengan subjudul abu ±1,6 %.
- Adegan data punya tekstur kertas nyata dan label 3 ukuran (kedalaman Z), bukan bidang datar.
- Kamera bergerak di setiap still berurutan (push/pan ≥ 0,5 %/0,2 dtk); tidak ada cut keras tanpa objek penghubung.
