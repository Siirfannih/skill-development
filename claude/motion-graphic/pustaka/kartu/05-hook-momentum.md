## PENGIKAT (diambil utuh dari SATU kiblat; ini yang membuat video terasa satu keluarga)

### 1. Warna & tekstur
- Dua dunia bergantian: gelap (`#001013` playlist/drafts, `#101A21` judul tebal, `#151619` jam, `#181612` clapper) dan terang (`#EEEEEE` post IG/kartu/kinetik, `#FFFFFF` notes/kalimat).
- Aksen: hijau terang `#00FD6C` (bintang kilau), hijau neon tombol `#5DB903`, hijau gelap teks kinetik `#0C5B29`; biru ikon iOS `#0C8FFF`; oranye poster `#D76730`, merah neon `#C04E1E`; kuning "WATCH". Hijau satu-satunya warna penekanan TEKS.
- Adegan gelap ber-vignette kuat: luma pusat/sudut 55/12 (poster), 96/11 (clapper), 48/25 (jam). Adegan putih rata, hanya bayangan lembut kartu.
- Tekstur taktil: kertas poster berlapis, meja kayu `#F3B578` dengan bayang jendela, bokeh lampu hangat, debu/grain di latar clapper, pendar neon, tepi gelap seperti film di kinetik tumpuk (latar `#ABABAB`).
- Grade: hangat oranye di benda 3D, teal-hitam di UI gelap; footage api jenuh oranye.

### 2. Teks
- Font (paling mirip): SF Pro/Inter untuk UI & kalimat lepas (Bold untuk kalimat, Regular di kartu); display condensed heavy ala Anton/Bebas untuk poster dan "INNOVATING / THEM"; lettering komik tangan di balon iPhone ("NAH, I'D WIN."); typewriter di label clapper.
- Teks hampir selalu MENEMPEL benda/UI: judul poster, judul lagu playlist, label tombol "Let / them", balon lock screen, ketikan notes, baris kartu, kolom input drafts, judul di atas tumpukan buku+jam.
- Kalimat lepas di latar putih: satu baris di tengah (cx 49 %, cy 50 %), 3–4 kata, tinggi huruf 3,3 % ("But brands can't") s.d. ±3,8 % kapital ("You'll keep moving."), lebar 55–82 %.
- Tumpukan judul di atas objek: "They / can't / steal" = 7–8,4 % : 2,4 % (rasio ±3,5), coklat redup `#654B44` di atas buku+jam, cy 31–41 %.
- Kinetik tumpuk: semua baris SAMA besar (±9,1 % tinggi, jarak baris 11 %), penekanan hanya warna (hijau gelap di kolom tengah, sisanya abu `#BABABA`).
- Judul gelap tebal: "THEM" 16 % tinggi, "INNOVATING" ±7 %; putih bertepi/ekstrusi, miring; satu kata kuning ("WATCH").
- CTA: "Visit now" 7,2 % + "& download it" 4,3 % (rasio 1,7), rata kiri x 12 %, di bawah clapper.
- Penekanan: ganti warna kata ("can't" hijau + garis bawah bergelombang), kilau bintang hijau, abu → hitam saat kata diucapkan ("moving."), ukuran (THEM).
- Masuk/keluar: sigap. Diketik dengan kursor (notes, kolom input), muncul per kata (abu dulu lalu hitam), baris kartu mengetik dari kiri, balon chat pop. Keluar biasanya terbawa cut/dorongan kamera, bukan fade.

- Satu-satunya footage: klip api (motor terbakar) DIBINGKAI di dalam kartu UI drafts ("They might match your features"), diberi judul putih "NEVER MATCH" (27–30 dtk).
- Sisanya render benda 3D/foto: poster kertas, iPhone di meja kayu, jam digital + buku, clapper board, headphone/kamera melayang. Benda dipilih harfiah dari kalimat (jam "can't steal" waktu, clapper "After effect users").

### 5. Motion graphic
- UI asli sebagai panggung, lengkap: playlist bergaya Spotify (judul lagu = kalimat), post IG (like 3,825, akun terverifikasi), lock screen iPhone, Notes, kartu daftar ber-ikon, kolom compose X/Threads, antarmuka kamera iPhone (SLO-MO/VIDEO/PHOTO).
- Tombol neon pendar (Let/them/MIMIC/COLOR) yang ternyata gambar di dalam post IG (zoom-through 5,3 dtk).
- Bintang kilau hijau besar buram di sekitar kalimat; kinetik tumpuk berulang "Let them replicate".
- **Skala subjek:** satu subjek besar per adegan: iPhone 66–83 % lebar × 66–82 % tinggi; kartu daftar 77 × 50 %; gambar post IG ±85 × 44 %; clapper 77 × 28 % di atas; poster ±46 × 36 % dikelilingi kertas lain (pembuka satu-satunya adegan banyak objek). Notes & kinetik memenuhi frame.
- **Kedalaman:** 2–3 lapis di adegan gelap/benda (latar bokeh atau kayu, subjek tajam, lapisan depan buram: pita kuning di poster, benda melayang di judul tebal, UI kamera di clapper); depth of field sempit dan miring di playlist; adegan putih datar (hanya bayangan kartu).

### 6. Kamera & transisi
- Gerak kamera (cv2, akumulasi antar-frame; perkiraan): poster push ×2,0 + putar 22° dalam 1,6 dtk; playlist push +60 % + putar; iPhone pan besar (±110 % lebar) dengan skala tetap; jam push pelan +6 %; kartu push +26 % sambil pan mengikuti ketikan; bintang push +88 % dalam 2 dtk; kinetik tumpuk push +53 %; judul tebal push +13 %; drafts pull −46 % + pan; clapper pull −38 %.
- Transisi: whip berblur + rotasi (0→1,6), hard cut di kata (4,93; 7,33; 11,27; 23,73 dengan hit), zoom-through/pull dari tombol ke post IG (5,3), slide/morph putih-ke-putih (15,3; 20,6; 22,3), dissolve-blur ±0,8 dtk ke UI kamera (30,3–31,1).
- Pemicu: kata kunci VO; 93 % cut punya onset audio dalam 100 ms (earshot).

### 7. SFX
- earshot `--detail high`: 217 onset (6,0/dtk), 96 berlabel: 9 hit, 6 foley/pop, 5 UI (chat pop), 3 riser, 2 whoosh, 1 shutter; sisanya suara.
- Pop/klik saat teks/balon muncul (18,04 dtk +16 dB), hit pada hard cut (23,78 +14,7 dB), riser sebelum ganti babak (12,69; 16,87; 29,56), whoosh di gerak kamera (7,59; 17,48), shutter + stab orkestra di akhir.
- SFX duduk di dalam mix (umumnya < 12 dB di atas bed); aksen terkuat tetap suara. Level SFX terpisah: Tidak terukur: tanpa stem.

### 8. Musik
- Bed "inspirational corporate / aggressive" dengan vocal chop (label earshot, lemah); ±136 bpm (librosa), grid ketukan tidak tegas (pulse clarity 0,06).
- Mix sangat padat: −14,4 LUFS, true peak −2,1 dBTP, LRA 1,6 LU; RMS per 3 dtk −16 s.d. −18,5 dB (tanpa babak sunyi). VO pria sepanjang video.
- Perubahan per babak: 3 seksi earshot (0–5,6 / 5,6–27 / 27–36) tanpa perubahan level berarti; puncak 28,5–31,5 dtk (−13,2 LUFS).

## Cek kemiripan (dipakai juri saat menyandingkan still)
- Teks utama menempel di benda/UI yang dikenali (tombol, balon, notes, kartu, poster, input), bukan melayang di latar kosong; kalimat lepas hanya di latar putih/abu `#EEEEEE`–`#FFFFFF`.
- UI digambar lengkap (status bar, angka like, ikon, kursor), font UI sans gaya SF Pro.
- Satu subjek besar per adegan (iPhone/kartu/clapper ≥ 66–77 % lebar); bukan banyak objek kecil, kecuali pembuka.
- Kalimat lepas: satu baris di tengah, huruf 3–4 % tinggi, lebar 55–82 %.
- Judul di atas objek: kata kunci 7–8,5 % dengan kata sambung ±2,4 % (rasio ≥ 3); judul tebal display bisa sampai 16 %.
- Kinetik tumpuk: semua baris sama besar (±9 %), hanya warna yang membedakan (hijau gelap vs abu).
- Hijau satu-satunya warna penekanan teks; adegan gelap ber-vignette kuat (sudut ≤ 25 dari 255).
- Adegan benda punya 2–3 lapis dengan latar bokeh/kayu atau lapisan depan buram; tidak ada frame tanpa gerak kamera.
- CTA rata kiri di bawah objek, "Visit now" ±7 % dengan baris kedua ±4 %.
