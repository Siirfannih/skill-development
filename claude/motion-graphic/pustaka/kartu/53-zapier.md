## PENGIKAT (diambil utuh dari SATU kiblat; ini yang membuat video terasa satu keluarga)

### 1. Warna & tekstur
- Teks hitam di krem; teks putih di cokelat gelap; oranye sebagai aksen kata kunci dan sebagai layar penuh.
- Glitch/negatif gelap di momen "Not any more".
- Hex, grain dan tekstur: tidak terukur.

### 2. Teks
- Dua skala saja: kalimat kecil ±3 % tinggi frame, dan kata hero raksasa ≥60 % tinggi frame ("Automate").
- Kalimat di tengah (y ≈ 50 %); daftar fitur di tengah dengan label di kiri.
- Sentence case. Kalimat pembuka masuk dengan cara diketik; kata hero disapu pan horizontal ber-motion-blur.
- Penekanan lewat warna oranye pada kata kunci.
- Tanpa teks di transisi blob, lanskap (selain UI), dan avatar akhir.
- Font dan bobot: tidak tercatat.

### 3. Ritme
- Babak: kalimat masalah → glitch pembalik → kata hero → daftar fitur → angka "9000+" → diagram → prompt box di lanskap → logo/avatar.
- Tiap pergantian besar ditandai satu sub hit; item daftar ditandai sepasang tik.
- Cut/menit dan shot median: tidak terukur.

## TEKNIK (boleh dipinjam referensi lain; selalu dikenakan pengikat kiblat)

### 4. B-roll / footage
- Lanskap sebagai latar prompt box; avatar di akhir. Jenis dan perlakuan lain: tidak terbedah.

### 5. Motion graphic
- Teks diketik; glitch gelap; bar oranye yang berubah jadi blob; morph blob-mask sebagai transisi.
- Kata raksasa, daftar fitur yang berganti, angka "9000+", diagram, UI prompt box, logo.
- **Skala subjek:** kata hero mengisi ≥60 % tinggi frame; kalimat lain ±3 %
- **Kedalaman:** tidak tercatat

### 6. Kamera & transisi
- Pan horizontal menyapu kata raksasa (whip-pan + motion blur); zoom-in ke blob/logo; push-in ke UI.
- Transisi: glitch/negatif gelap (0,4 dtk), morph blob-mask, hard cut ke oranye penuh.

### 7. SFX
- Hierarki: sub thud = momen kunci, tik = item daftar, riser/swish = paling pelan. Level RMS 300 ms, relatif bed:
  - Impact/sub (centroid 45–170 Hz): −18,8 dBFS (−21…−16), +17,7 dB di atas bed; 11 kejadian.
  - Badan whoosh 0,5–2 kHz: −21,3 dBFS, +14,7 dB; 5 kejadian.
  - Riser/swish udara (centroid 4–11 kHz): −25,1 dBFS, +9,1 dB; 6 kejadian.
  - Tik UI (centroid 1,5–2,3 kHz, hangat, bukan 4 kHz): −21 dan −23,5 dBFS, berpasangan dengan jarak ±0,13–0,15 dtk, +9…+15 dB.
- Thud logo akhir = bunyi terkeras: −11,6 dBFS RMS (puncak −1 dBFS), +25 dB di atas bed. Puncak sampel SFX lain −1…−9 dBFS.
- SFX keseluruhan RMS −25,3…−16,1 dBFS (median −21,0), yaitu +6…+25 dB di atas bed (median ±+14).
- Sinkron: 78 % impact dalam ±83 ms (2 frame) dari peristiwa visual, median +20 ms. Riser mulai ±400 ms sebelum visual dan memuncak tepat di frame transisi.

### 8. Musik
- Tanpa VO. Mix −17,8 LUFS; true peak +2,0 dBTP (over; jangan ditiru); LRA 8,7 LU.
- Bed: lantai −35,1…−23,4 dBFS (median −32,8); 100 % waktunya di dalam −41…−21 dBFS. Tidak pernah mati: 0 dead air, minimum −38 dBFS.
- Satu palet dengan filter sweep per babak: terang (rolloff ±10 kHz) di pembuka, di-low-pass (rolloff ±4,5 kHz) di bagian fitur, terbuka lagi di bagian hasil/solusi.
- Lantai bed turun (−23,5 → −28) saat glitch pembalik. Tekanan dibuat dengan filter, bukan dengan senyap.
- Bpm dan instrumen: tidak terukur.

## Cek kemiripan (dipakai juri saat menyandingkan still)
- Hanya dua skala teks: kalimat ±3 % tinggi frame di y ≈ 50 %, dan kata hero ≥60 % tinggi frame.
- Palet teks/latar hanya hitam di krem, putih di cokelat gelap, oranye sebagai aksen.
- Bed non-vokal tidak pernah di bawah −38 dBFS; lantainya di dalam −41…−21 dBFS.
- SFX +6…+25 dB di atas bed; sub thud +15…+20 dB, tik +9…+15 dB, riser/swish ±+9 dB.
- Bunyi terkeras seluruh video jatuh di logo akhir.
- Tik UI ber-centroid 1,5–2,3 kHz, berpasangan.
- True peak ≤ −1 dBTP (sumbernya sendiri over di +2,0; tidak ditiru).
