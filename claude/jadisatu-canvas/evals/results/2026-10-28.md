## Cakupan dan batas

Ini evaluasi dokumentasi dan protokol secara offline, bukan uji login semua penyedia atau bukti bahwa UI web mereka mendukung MCP. Tidak ada build, browser, panggilan model berbayar, pembuatan token, perubahan global klien, atau mutasi Canvas langsung. Evaluasi offline ini mendahului audit integrasi akhir.

## Pemeriksaan mekanis

- Repo tidak memiliki validator skill executable; `tools/sync.sh` adalah penyalin global dan tidak dijalankan.
- Validator bundel `skill-creator/scripts/quick_validate.py`: **PASS**. Skill inti 66 baris; referensi klien 175 baris.
- JSON dalam 7 code fence, TOML dalam 2 fence, Python dalam 1 fence dan shell dalam 1 fence: **PASS**. JSON kasus offline juga valid.
- Kedua konfigurasi bridge dieksekusi terhadap executable `node` tiruan di direktori sementara. Path dan pemetaan `MCP_URL`/`MCP_TOKEN` cocok dengan kontrak. Token sintetis tidak menjadi argumen proses: **PASS**. Tidak ada koneksi jaringan.
- Tautan referensi skill lokal, pemindaian nilai token Canvas terisi, dan `git diff --check`: **PASS**.
- Format dan dukungan klien diverifikasi dari halaman primer yang ditautkan di referensi, serta `codex mcp add --help` dan `codex mcp login --help` lokal. Tidak menjalankan perintah pemasangan/login.

## Skenario perilaku

Kasus: [reset-conflict.json](../cases/reset-conflict.json). Brief lama berlanjut setelah pemilik memakai ulang room; satu gambar aktif dan konteks generasi 3 dibaca, lalu percobaan tulis berkonflik karena reset kedua ke generasi 4. Pengguna juga meminta Gemini dihubungkan agar terus mengawasi.

| Assertion | Baseline tanpa skill | Agent segar dengan skill |
|---|---|---|
| Membaca board segar dan gambar aktif; tidak mengarang piksel mock | PASS | PASS: `read_board {}` lalu `read_image {"assetId":"cafe-logo"}`; warna usulan ditandai tidak disampel dari logo |
| Menulis dengan generasi 3; setelah 409 membaca ulang tanpa mengulang kartu di generasi 4 | PASS | PASS: usulan `add_card` memakai `contextVersion:3`; setelah konflik meminta brief/referensi saat ini |
| Membuang item, aset dan revisi lama | PASS | PASS: tidak memakai `draft-a`, `old-logo` atau revisi 4 yang diingat |
| Tidak menciptakan izin penyedia, reset model atau pengawasan idle | PASS | PASS: Gemini tidak diklaim terhubung; watcher memerlukan pelaksanaan terpisah yang diotorisasi |

Baseline sudah mengambil keputusan aman, sehingga hasil ini **tidak membuktikan peningkatan perilaku dibanding baseline**. Nilai skill yang diuji adalah ketersediaan endpoint, parameter generasi/revisi, batas reset dan contoh klien dalam satu referensi yang dapat ditemukan ulang. Agent uji tidak membaca assertion atau hasil baseline.

Cuplikan hasil agent dengan skill: “No note was saved or verified. The board reset during the attempt, logo colors were not observed, and Gemini was neither connected nor monitoring.” Ini hasil mock; bukan laporan keadaan workspace produksi.
