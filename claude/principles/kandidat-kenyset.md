# Kandidat: pustaka Kenyset

**Usulan.** Kenyset FREE SFX PACK (lisensi Pixabay) adalah pustaka yang dipakai di The Gap, dengan label hangat, pakai dengan low-pass, atau tajam. Itu pengalaman satu proyek, bukan pustaka utama setiap video.

**Kenapa dicatat.** Sesi sound design Video 3 pernah menilai hasil dari pertanyaan "apakah ini Kenyset". Proyek itu belum memilih pustaka.

**Cocok bila.** Berkas standar suatu proyek menyebut Kenyset, atau Irfan menyerahkan foldernya.

**Lewati bila.** Nama Kenyset tidak ada di berkas standar. Folder SFX yang diberikan Irfan untuk satu proyek tetap sumber pertama proyek itu, bukan untuk proyek lain.

**Benchmark (bukan target).** Tidak ada jumlah file wajib. Pemetaan nama file di `claude/motion-graphic/references/audio.md` milik konteks yang menulisnya.

**Contoh.** The Gap v8–v18. Menunggu pilihan per proyek.
