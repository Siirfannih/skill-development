# Kartu prinsip

Satu kartu, satu gagasan. Angka di kartu adalah benchmark dari video yang disebut, bukan syarat proyek lain. Proyek memakai kartu hanya bila `BRIEF-STANDARD.md`-nya memilih.

## Desain gambar

| Kartu | Kapan dibuka |
|---|---|
| `hook-awal` | Membuka video. |
| `ritme-naik-lalu-reda` | Mengatur tempo potongan. |
| `muncul-lalu-drift` | Memunculkan objek atau teks. |
| `teks-sedikit` | Menentukan seberapa banyak kata di layar. |
| `satu-font-aksen` | Memilih pasangan font. |
| `gambar-diam-tetap-bergerak` | Memakai foto atau lukisan. |
| `subjek-dipisah` | Menaruh teks dan orang dalam satu frame. |
| `ui-pegas` | Menganimasikan UI. |
| `satu-fokus` | Menyusun apa yang dilihat mata. |
| `tekan-dengan-huruf` | Menekankan satu kata. |
| `jangan-bawa-template` | Memulai proyek baru. |

## Suara

| Kartu | Kapan dibuka |
|---|---|
| `gerak-bermakna-bersuara` | Merancang SFX. |
| `musik-mengikuti-babak` | Merancang musik. |
| `telinga-nyaman` | Memilih warna bunyi. |

## Menunggu Irfan (`proposal`)

Bukan syarat. `usulan-kotak-aksen`, `usulan-montase-banyak-fokus`, `usulan-pita-2-6-khz`, `usulan-sinkron-dan-loudness`.

Kandidat yang sumbernya tidak ada di repo, atau hanya milik proyek lain: `kandidat-rekaman-asli`, `kandidat-kenyset`, `kandidat-kepadatan-sfx-launch`.
