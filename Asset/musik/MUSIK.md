# Asset / musik · katalog lagu dan paket audio referensi

Katalog lagu yang muncul di video referensi. Dipakai di fase musik: pilih lagu yang tempo dan suasananya cocok dengan video yang sedang dikerjakan (`claude/motion-graphic/guide/audio/GUIDE.md`), bukan lagu favorit.

**Letak file audio:** di folder ini pada mesin kerja (PC server), nama file `<Artis> - <Judul>.<ext>`. `.gitignore` menahan semua file audio, jadi yang ada di git hanya katalog ini. Bila file hilang dari mesin, ambil ulang lewat kolom Link.

**Kolom Status:** `pasti` = judul dan artis terbaca jelas di video sumber; `judul pasti` = artis belum dicek; `dugaan` = belum dikonfirmasi. File belum ada di mesin = kolom File kosong.
