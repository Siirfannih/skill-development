## Cross-video visual patterns

| Pattern | Observation |
|---|---|
| Subject isolation | Roto / mask; text sandwiched between background and subject |
| Motion on stills | No truly static image — 2.5D parallax push on photos/art |
| Contrast | High contrast grade / type vs plate |
| “Pop and drift” | Opacity/scale 0→100% in 3–4 frames, then 100→105% drift; almost no fades |
| UI easing | Spring with slight overshoot |
| Typography | Heavy sans-serif (SF Pro / Inter / Helvetica-like); **1–3 words per screen** synced to syllables; text tracks subjects; one contrasting font as theme accent |
| Structure | Hook in first ~3 s → escalation edit with ≤0.5 s cuts mid → “breathe” resolution, slower ending |
